# Self-RAG for Books

A retrieval-augmented generation system for summarizing large PDF books and answering questions using open-weight language models.

## Planned Features

- Extract text from large digital and scanned PDF books
- Preserve chapter, section, and page information
- Generate hierarchical book summaries
- Answer questions using retrieved evidence
- Include page-level citations
- Evaluate whether answers are relevant and supported
- Retry retrieval when the available evidence is insufficient
- Produce structured Markdown with headings and bullet points
- Highlight important keywords
- Support parameter-efficient model fine-tuning
